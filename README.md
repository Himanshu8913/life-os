# Life OS

A local-first personal operating system for managing and visualizing your life.

- No accounts, no backend, no AI APIs
- All data stays on your device (IndexedDB)
- RPG-style progression: quests, XP, levels, achievements


## Development

```bash
npm install
npm run dev
```

```bash
npm run build    # production build
npm run test     # unit tests
npm run lint     # lint
```

## Stack

TypeScript · React · Vite · Zustand · Dexie · Tailwind CSS · Framer Motion
